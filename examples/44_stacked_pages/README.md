# 44 堆叠页面与窗口切换

[阅读讲解](../../docs/chapters/33-stacked_pages.md) · [构建说明](../../docs/getting-started.md)

使用 Qt Creator 打开 `44_stacked_pages.pro`，选择匹配的 Qt 6 Kit 构建运行；或从仓库根目录用 CMake 构建 `44_stacked_pages` 目标。

本步目录内的源文件、头文件、资源和 `.ui` 是一个整体。`verify.h`（如有）用于可选自动检查，普通运行不会自动点击按钮。
