# 47 重写 event 拦截 Tab

[阅读讲解](../../docs/chapters/36-event_tab.md) · [构建说明](../../docs/getting-started.md)

使用 Qt Creator 打开 `47_event_tab.pro`，选择匹配的 Qt 6 Kit 构建运行；或从仓库根目录用 CMake 构建 `47_event_tab` 目标。

本步目录内的源文件、头文件、资源和 `.ui` 是一个整体。`verify.h`（如有）用于可选自动检查，普通运行不会自动点击按钮。
