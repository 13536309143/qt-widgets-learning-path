# 第 1 章 Qt概述


先建立对 Qt、Qt Creator 和 Qt Widgets 的整体认识，再进入项目创建与具体控件。本教程按照当前学习内容组织成十一章，章节编号表示知识结构，示例编号表示独立项目。

## Qt能做什么

Qt 是提供窗口、控件、对象通信、事件处理和绘图等能力的 C++ 框架。本教程使用 Qt Widgets 与 C++17，学习如何创建桌面窗口、响应用户操作，并把界面、对象状态和业务逻辑组织清楚。

界面并不是一张静态图片：程序先创建对象与窗口，再进入事件循环。用户点击按钮、输入文字或拖动窗口时，Qt 处理对应事件，并根据连接关系调用处理代码。

## 分清框架与开发工具

| 名称 | 负责什么 |
|---|---|
| Qt | 提供类、模块与运行所需的框架能力 |
| Qt Widgets | 提供 QWidget、按钮、输入框、布局和桌面界面组件 |
| Qt Creator | 编辑项目、配置 Kit、调用构建工具、运行与调试 |
| 编译器与链接器 | 把 C++ 源码和需要的库构建成程序 |
| qmake | 读取 .pro，生成构建规则 |
| Designer | 编辑 .ui 中的控件、属性与布局 |

不要把 Qt Creator 当作编译器，也不要把 .pro 当作可执行文件。各工具如何协作，在第二章结合实际项目理解。

## 先认识几个基础类

QApplication 管理 GUI 应用的公共资源与事件处理；QObject 提供对象树和信号槽的基础；QWidget 是窗口与可视控件的基础；QMainWindow 提供主窗口框架；QDialog 用于对话式交互。后面的章节会逐一展开，不要求现在记住所有成员函数。

## 本教程的学习方法

每节先理解要解决的问题，再运行一个对应示例，阅读 .ui 和窗口类，预测修改结果，最后重新构建验证。遇到问题先区分编译失败、运行后没有反应、运行结果不符合预期，分别追踪构建配置、连接关系和数据变化。

教程按十一章组织，52 个项目的编号与所属章节一致。第一章先理解概念，第二章开始按小节顺序打开项目；例如项目 2.2 讲解 Designer 与 setupUi。
