## 检查实际做了什么

01—30 包含窗口运行、按钮调用、输出展示和截图等基础检查，其中部分是冒烟检查。31—48 按示例提供具体状态检查，例如页面索引、字体字号、关闭确认、鼠标坐标和 Tab 处理。49 使用临时文件验证中文与换行的保存读回，50 验证三种对话框的返回顺序，51 验证过滤器结果，52 同时验证颜色状态和红色绘制像素。

这些检查不意味着每个操作系统主题、DPI、文件权限、文本编码和交互分支都已覆盖。文件选择例子自动检查取消路径，成功单选与多选仍应按章节做手动练习。文本编辑器的自动检查只在自己建立的临时目录内读写。

## 怎样重新检查

```sh
ctest --test-dir build --output-on-failure
```

每个程序也支持 `--verify 输出目录`，保存检查状态与实际控件渲染截图。Windows 使用本机窗口后端以取得系统字体，Linux CI 使用 offscreen 后端和已安装的字体。offscreen 的图像是程序真实渲染，不包含系统窗口标题栏。

失败时先看 CTest 对应项目，再查看 build/verification-output 下的状态和图像。不要为了“变绿”移除失败断言；先确认环境是否满足条件，再判断程序是否有错误。
